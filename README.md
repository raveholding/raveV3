# raveV3 · Demo SISTEMA VB con asistentes inteligentes SVB R2AVE

Demo de **Vincular Business** para mostrar el **Centro Inteligente**: comercio genérico de un solo dueño («Mi Comercio», datos de ejemplo) con el equipo **SVB R2AVE** y su **centro de operaciones vivo**, y el **mapa básico** del local (automático por categorías). No lleva datos ni personalización de Almacén RAVE (sin editor del local, sin plano de ejemplo SVB, sin personal con fotos).

- Publicación: `https://raveholding.github.io/raveV3/` (GitHub Pages desde `main`, carpeta raíz).
- Ingreso de prueba: usuario **ADMIN**, clave **1234**. Datos de ejemplo.
- `index.html` se genera desde `AlmacenRAVE/fuente` con `python3 build.py v3` (rama `main`). No se edita a mano.
- Requisitos, estado y límites de esta versión: [PROMPT_DEMO_RAVEV3_ASISTENTES.md](PROMPT_DEMO_RAVEV3_ASISTENTES.md).
